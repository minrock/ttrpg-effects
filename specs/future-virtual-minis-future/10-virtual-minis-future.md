# Spec 10 - Minis Virtuales y Marcadores Futuros

## Objetivo

Definir un modulo futuro opcional para tokens, minis virtuales o marcadores sin afectar el flujo principal de minis fisicas.

## Alcance futuro

- Crear tokens.
- Mover tokens sobre la grilla.
- Asociar tokens a luces o vision.
- Guardar tokens en la escena.
- Ocultar tokens si existe una vista separada de control.

## Fuera del MVP

- Combate automatizado.
- Hojas de personaje.
- Iniciativa.
- Sincronizacion online.
- Automatizacion completa de reglas.

## Principios

- Las minis fisicas siguen siendo el caso principal.
- Los tokens no deben ser requeridos para usar luces o herramientas.
- Los tokens deben ser una capa opcional.
- El usuario debe poder ignorar completamente este modulo.

## Criterios de aceptacion futura

- El usuario puede crear un token simple.
- El token puede moverse con snap-to-grid.
- El token puede tener una luz asociada.
- El token se guarda y carga con la escena.

## Riesgos

- Convertir la app en un VTT completo antes de resolver la mesa fisica.
- Agregar complejidad visual innecesaria sobre la proyeccion.
- Confundir tokens virtuales con minis reales durante una sesion.

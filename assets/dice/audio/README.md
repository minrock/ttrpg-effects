# Dice roll sounds

Source: [Casino Audio 1.1 by Kenney](https://kenney.nl/assets/casino-audio).
License: Creative Commons Zero (CC0); upstream notice in `License.txt`.
Retrieved 2026-10-25 from the download linked by the author:
https://kenney.nl/media/pages/assets/casino-audio/2472606a04-1721639069/kenney_casino-audio.zip

- `die-throw-1.ogg` through `die-throw-4.ogg`: one physical die.
- `dice-throw-1.ogg` through `dice-throw-3.ogg`: multiple physical dice.

The seven original OGG files are unmodified (approximately 62 KiB combined).
Playback skips recording lead-in and uses short, gain-limited samples aligned to
the existing physics replay, with minor playback-rate variation. No audio is
downloaded at runtime. License text is preserved with whitespace normalized.

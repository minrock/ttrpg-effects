# Identidad visual

- `ttrpg-effects-icon.png`: simbolo sin letras usado por la UI, las ventanas, el Dock y el instalador.
- `ttrpg-effects-icon.ai`: fuente editable del simbolo.
- `ttrpg-effects-wordmark.png`: propuesta completa con el nombre TTRPG EFFECTS.
- `ttrpg-effects-logo.png`: logo historico conservado como respaldo.

La variante sin letras es la unica referencia activa desde el codigo. Electron-builder deriva de ella los recursos nativos durante el empaquetado. La identidad fue creada para el proyecto a partir del contexto de sus mapas tacticos, grillas, luz, fuego y agua; no incorpora assets externos.
